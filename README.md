# Calorie Tracker

Single-page calorie tracker built with React.

## Features
 
- **Calorie goal** — set a daily calorie target and track your progress
- **Macro targets** — recommended protein, carbs, and fat targets auto-calculated from your calorie goal using a standard 25/50/25 split
- **Custom macro split** — override the default percentages to match your own diet goals
- **Food log** — add/remove food entries with calories and optional macros
- **Progress bars** — per-macro bars fill toward your target and turn red if exceeded
- **Over/remaining indicators** — calorie bar and macro cards show how much you have left or how far over you are

## Setup
 
```bash
# Install dependencies
npm install
 
# Start the development server
npm start
```
 
Requires Node.js and a React project setup (e.g. Create React App).
